1. PROJECT OVERVIEW
================================================================================

Lector is an RSVP (Rapid Serial Visual Presentation) speed-reading web app.
Users upload a PDF or EPUB; the app extracts text in the browser and displays
it one word (or small chunk of words) at a time at a configurable speed. All
processing is client-side: no API routes, no server upload. Session state
(current book + position) and preferences (WPM, chunk size, font size, theme)
are stored in the browser’s localStorage.

Key behaviors:
  - PDF and EPUB upload via drag-and-drop or file picker (accept=".pdf,.epub").
  - Display modes: single word, 2-word chunks, or 3-word chunks.
  - Speed: 100–1000 WPM via slider.
  - Font size: 28px–96px.
  - Progress bar: words read, percentage, estimated time remaining.
  - Chapters: PDF outline / EPUB TOC used for a chapter dropdown; jump to chapter.
  - Theme: dark (default) or light; persisted in localStorage (rsvp_theme).
  - Focus mode: when playing, header/meta/progress blur and dim so focus stays on the word.
  - Optional UI sounds: soft clicks for play, pause, step, toggle (Web Audio API; no files).
  - Resume: last book and position restored from localStorage on load.
  - Keyboard: Space = play/pause, Left/Right = step backward/forward.

================================================================================
2. TECH STACK
================================================================================

  - Next.js 14 (Pages Router)
  - React 18
  - TypeScript (strict)
  - pdfjs-dist — PDF text extraction and outline (client-side, in browser)
  - epubjs — EPUB parsing and TOC (client-side, in browser)
  - Vitest — unit tests for lib/ helpers (rsvp, pdfText, sounds)

  No server-side PDF/EPUB API: no pdf-parse, no formidable. All parsing runs
  in the browser.

4. MAJOR FILES — WHAT EACH DOES
================================================================================

--- pages/_app.tsx
  - Root component for every page.
  - Imports ../styles/globals.css so CSS variables and base styles apply app-wide.
  - Renders <Component {...pageProps} /> (no layout wrapper or providers).

--- pages/index.tsx
  - The only page: upload + reader UI and all client state.
  - State: reader (text, fileName, wordCount, pages, chapters), prefs (wpm, chunkSize, fontSize),
    chunks, index, playing, dragOver, loading, error, showSettings, mounted, theme (dark|light).
  - On mount: reads localStorage (PREFS_KEY, STORAGE_KEY, rsvp_theme), restores prefs, theme,
    and last session (reader + index). Normalizes readerState.chapters to array if missing.
  - Theme: applied via document.documentElement.dataset.theme = 'light' (dark = no attribute);
    CSS [data-theme="light"] in globals.css overrides :root variables.
  - When reader or chunkSize changes: tokenizes reader.text via lib/rsvp, builds chunks,
    rescales index proportionally.
  - Persists: prefs, theme, and session (reader + index) to localStorage when they change.
  - Playback: when playing, setInterval advances index at (60000/wpm)*chunkSize ms per chunk;
    stops at last chunk; sounds.play() / sounds.pause() on toggle.
  - Upload: handleFile validates .pdf or .epub.
    - PDF: FileReader → ArrayBuffer → pdfjs-dist getDocument; getPage(i) → getTextContent →
      items[].str joined per page; pageWordCounts for chapter mapping; getOutline() →
      collectOutlineItems → page index → chapterWordIndex(pageIndex, pageWordCounts) →
      chapters[{ title, wordIndex }]. Full text cleaned with lib/pdfText.
    - EPUB: URL.createObjectURL(file) → epubjs(blobUrl); spine sections loaded, inner
      HTML stripped to plain text; navigation.toc mapped to spine indices and word offsets
      for chapters. Blob URL revoked in finally.
  - Renders: header (wordmark, theme toggle, “New Book” when loaded); upload section when
    !reader; “No text found” when reader but chunks.length === 0; when reader && chunks:
    book meta, chapter <select>, progress bar, word/chunk display, play/pause/step/settings,
    settings panel (WPM, chunk size, font size), keyboard hint. Focus-blur class on header
    and meta when playing.
  - KeyboardHandler: Space / ArrowLeft / ArrowRight when book loaded and chunks exist;
    initSounds() and sounds used on interaction.
  - Styles: large inline “styles” object (React.CSSProperties) using CSS vars from
    globals.css (--bg, --text, --gold, etc.). Inline keyframe + class for word animation
    and spinner.

--- lib/rsvp.ts
  - Pure functions used by the UI (and tests). No React, no Node APIs.
  - tokenize(text): split on whitespace, filter empty → string[].
  - buildChunks(words, size): for size 1 returns words; for 2/3 returns array of
    "word1 word2" etc.; last chunk may be shorter.
  - progressPercent(index, totalChunks): 0–100; single-chunk content = 100%.
  - wordsReadEstimate(index, totalChunks, totalWords): approximate words “read”.
  - minutesRemaining(index, totalChunks, chunkSize, wpm): estimated minutes left;
    guards wpm with Math.max(1, wpm).
  - chapterWordIndex(pageNumber, pageWordCounts): returns word index of first word
    on the given page (0-based); used to map PDF outline / EPUB TOC to chunk index.

--- lib/pdfText.ts
  - cleanExtractedPdfText(raw): normalizes \r\n → \n, collapses 3+ newlines to \n\n,
    trims. Used on client after pdfjs-dist text extraction.
  - countWords(text): split on whitespace, filter Boolean. Same definition as UI
    so word counts are consistent.

--- lib/sounds.ts
  - Web Audio API: single shared AudioContext; initSounds() unlocks context (call once
    from a user gesture, e.g. first button click).
  - Generates short “click” tones (no audio files): white noise through lowpass + gain.
  - sounds.play(), sounds.pause(), sounds.step(), sounds.toggle() used by index.tsx
    for play/pause/step and theme/new-book actions.

--- styles/globals.css
  - Imports Cormorant Garamond and Cormorant from Google Fonts.
  - :root defines dark palette: --bg, --text, --gold, --gold-dim, --gold-border,
    --surface, --surface-2, --muted, --muted-2.
  - [data-theme="light"] overrides with light palette.
  - Global reset, html/body base, ::selection, scrollbar styling, button font,
    range input reset and thumb/track styling (WebKit + Moz).
  - @keyframes wordEnter for word entrance.
  - .focus-blur-transition, .focus-blur: when playing, non-focal UI is blurred and
    dimmed (filter, opacity, pointer-events: none).

--- vitest.config.ts
  - Test environment: node. Include: lib/**/*.test.ts.
  - Resolve alias @ → project root for @/ imports in tests (current tests use
    relative imports within lib/).

--- next.config.js
  - reactStrictMode: true. No other custom config.

--- tsconfig.json
  - Path alias "@/*" → "./*" so imports like @/lib/rsvp resolve.
  - strict, noEmit, jsx preserve for Next; includes next-env.d.ts and .next/types.

5. DATA FLOW
================================================================================

  Upload path (PDF):
    User selects/drops PDF → handleFile in index.tsx → FileReader.readAsArrayBuffer
    → pdfjs-dist.getDocument({ data: arrayBuffer }) → getPage(i).getTextContent()
    → per-page text joined; full text → cleanExtractedPdfText + countWords.
    getOutline() → collectOutlineItems → page index → chapterWordIndex → chapters.
    setReader(state), setIndex(0), persist to STORAGE_KEY.

  Upload path (EPUB):
    User selects/drops EPUB → handleFile → URL.createObjectURL → epubjs(blobUrl)
    → spine sections loaded, HTML stripped to plain text; navigation.toc → word
    offsets per chapter. setReader(state), setIndex(0), persist; URL.revokeObjectURL.

  Read path:
    reader.text + prefs.chunkSize → tokenize → buildChunks → setChunks.
    index + chunks drive: current chunk display, progress bar (progressPercent,
    wordsReadEstimate, minutesRemaining), chapter selector (word index → chapter),
    and interval-based advancement when playing.

  Persistence:
    PREFS_KEY: { wpm, chunkSize, fontSize }.
    STORAGE_KEY: { readerState: { text, fileName, wordCount, pages, chapters }, savedIndex }.
    rsvp_theme: 'dark' | 'light'.
    All written on change (after mount); session and prefs read once on mount.

6. RUNNING AND TESTING
================================================================================

  Install:    npm install
  Dev:        npm run dev          → http://localhost:3000
  Build:      npm run build
  Start:      npm start            → production server
  Test:       npm test             → vitest run (lib/*.test.ts)
  Watch:      npm run test:watch   → vitest in watch mode

  New tests: add *.test.ts under lib/; they are picked up by vitest.config.ts.

================================================================================
7. EXTENDING THE PROJECT
================================================================================

  - New API routes: add under pages/api/<name>.ts if needed; currently none.
  - New pages: add under pages/ (e.g. pages/about.tsx).
  - Reusable UI: consider a components/ folder and import into pages or _app.
  - Shared logic: keep it in lib/ and unit-test; import in pages.
  - PDF/EPUB behavior: change parsing in index.tsx (handleFile); keep word count
    and cleanup in sync with lib/pdfText and lib/rsvp tokenization.
  - Styling: globals.css for variables (dark + light) and base styles; index.tsx
    uses inline styles keyed off those variables. For new components, re-use the
    same vars for consistency.
